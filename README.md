## 💡 What is NotShovel?

**NotShovel** is a centralized content hub built specifically for developers, hackers, and tech creators. Instead of jumping across four different browser tabs to see what’s happening in tech, NotShovel aggregates the entire ecosystem into a single, clean dashboard:

* **🔥 Live Tech Stories:** Real-time top discussions and breaking news from Hacker News.
* **📦 Trending GitHub Repositories:** High-velocity open-source tools, libraries, and breakout projects.
* **📺 Curated Tech Media:** Real-time trending Science & Tech videos from YouTube with zero quota lag.
* **🎬 In-App Video Playback:** Watch tutorials, benchmarks, and tech deep dives right inside the platform without distractions.

---

## 👤 Unified Developer & Creator Profiles

Most platforms isolate your work: your code is on GitHub, your videos are on YouTube, and your discussions are scattered elsewhere. 

NotShovel unifies your online tech identity under one handle:

* **Your Code:** Showcases public repositories, stars, forks, and language stacks.
* **Your Channel:** Surfaces verified YouTube subscriber stats, recent uploads, and channel metadata.
* **Your Community:** Aggregates public discussions, karma, and submissions.

Search any developer handle (like `@freeCodeCamp` or `@google`), and NotShovel automatically bridges their code repositories with their creator channels.

---

## 🔍 Multi-Source Global Search

Type a single query into NotShovel's search engine to instantly query across four distinct dimensions at once:

1. **User Profiles:** Match developers and creators across the network.
2. **YouTube Content:** Find relevant videos and channels.
3. **GitHub Code:** Search top open-source projects.
4. **Community Stories:** Discover discussions and breaking articles.
